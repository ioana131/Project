Steps for opening the web pages:

1. Upload all these files on Visual Studio Code. 

2. Open a terminal.

3. Write the command: cd myblog

4. Then, write the command: python manage.py runserver

5. A link with the final project should be provided. (the link should look like this: http://127.0.0.1:8000/ )

Information regarding the project
For this project I worked alone and had to create a website for a blog. I worked in HTML, CSS, JavaScript, Django. Html was used to create and structure the content. In order to make the website look more presentable, I linked the HTML files with the CSS ones, changing the color of the texts, adding animations and with JavaScript files so that my webpage was interactive.

In this website I designed a blog home page with posts, a page with details about me, an interactive chatbot, a form that can be completed and a webpage of a gallery.
